3. Testy hodnot typu sentinel

NOBODY = sentinel("NOBODY")


def login(x):
    print(x == NOBODY)


login(42)
login("ROOT")
login(NOBODY)

NOBODY = sentinel("NOBODY")


def login(x):
    print(x is NOBODY)


login(42)
login("ROOT")
login(NOBODY)

NOBODY = sentinel("NOBODY")


def login(x = NOBODY):
    print(x is NOBODY)


login(42)
login("ROOT")
login(NOBODY)
login()

4. Specifikace typů proměnných i parametrů funkcí s využitím sentinel

NOBODY = sentinel("NOBODY")


def login(x: str | NOBODY = NOBODY):
    print("Performing login for:", x)


login(42)
login("ROOT")
login(NOBODY)
login()

values: dict = {}

print(values)

values: dict[str, int | NA | None] = {}

5. Alternativa k typu sentinel při definici funkcí s výchozími hodnotami parametrů

Poměrně často se v praxi můžeme setkat s funkcemi s volitelnými parametry. V případě, že tento parametr nebo tyto parametry nejsou předány při volání funkce, zapíše se do nich nějaká předem zvolená výchozí hodnota. U plně volitelných parametrů se mnohdy jako výchozí hodnota používá None, což má ovšem jednu nevýhodu – tímto způsobem totiž nelze odlišit explicitní předání None (to je totiž mnohdy zcela validní hodnota) od neuvedení parametru. V Pythonu 3.15 je doporučeno tento problém řešit s využitím typu sentinel tak, jak jsme si to ukázali v předchozích kapitolách. Ve starších verzích programovacího jazyka Python tento typ neexistoval, takže se používal zápis se třemi tečkami (ellipsis), což je hodnota typu ellipsis.

def bar(arg = None):
    if arg is None:
       print("No value provided!")
    else:
       print("Value provided", arg)
 
 
bar(42)
bar(None)
bar()

Povšimněte si, že v tomto případě volání funkce s předáním parametru s hodnotou None skutečně nebylo odlišeno od volání bez předání parametru:

Value provided 42
No value provided!
No value provided!

Tento problém lze do jisté míry vyřešit tak, že výchozí hodnotou parametru budou právě tři tečky:

def bar(arg = ...):
    if arg is ...:
       print("No value provided!")
    else:
       print("Value provided", arg)
 
 
bar(42)
bar(None)
bar()

Nyní lze snadno rozlišit volání s předáním None od volání bez uvedení parametru:

Value provided 42
Value provided None
No value provided!

Poznámka: pochopitelně i toto řešení má problém, a to při předání samotných tří teček:

def bar(arg = ...):
    if arg is ...:
       print("No value provided!")
    else:
       print("Value provided", arg)
 
 
bar(42)
bar(Ellipsis)
bar(...)
bar()

Nyní se od sebe neodliší poslední tři volání:

Value provided 42
No value provided!
No value provided!
No value provided!

Poznámka: ještě jednou si dovolím připomenout, že v Pythonu 3.15 se v takových případech doporučuje používat sentinel, i když osobně mi přijde zápis se třemi tečkami elegantnější.
